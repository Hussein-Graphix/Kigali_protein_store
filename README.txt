Kigali Protein Store - Deploy Ready Static Website

Files:
- index.html
- style.css
- script.js
- assets/

How to use:
1. Open index.html in a browser.
2. To receive WhatsApp orders, open script.js and replace:
   const WHATSAPP_NUMBER = '250788123456';
   with your real WhatsApp number in international format.
3. Upload the full folder to any static host such as Netlify, Vercel, GitHub Pages, or cPanel.

Features:
- Responsive ecommerce layout
- Product search and category filters
- Add to cart / quantity update / remove items
- LocalStorage cart persistence
- WhatsApp checkout with selected products and subtotal
